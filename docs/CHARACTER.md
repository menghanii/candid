# 캐릭터 닷(.) 가이드

candid. 로고 끝의 파란 마침표가 살아 움직이는 캐릭터. 친구들이 몰래 찍어 준 "진짜 나"를 모으러 다니는, 호기심 많은 점 하나.

- **2D 닷**: 기본. 앱 화면 안(시작 화면·빈 화면·완료·알림 창 등)에 지금 쓰는 버전
- **3D 닷 (클레이)**: 같은 모양에 무광 점토 질감. 지금은 정의만 해 두고, 마케팅 이미지·앱 스토어·공유 카드·굿즈 등 "크게 보여 줄 때" 쓸 예정

시안 페이지(비공개): https://claude.ai/artifact/NnBvShnts6DBcfdjHwYVj7

---

## 1. 모양 (2D 기본)

`viewBox 0 0 110 100` 기준 (꼬리 없으면 `0 0 100 100`)

| 부분 | 도형 | 값 |
|---|---|---|
| 머리 | 반원 | 중심 (50,50), 반지름 38 |
| 몸 | 사각형 (곧은 옆선) | x 12–88, y 50–80 |
| 아랫단 | 잔물결 5개 (2차 곡선) | 폭 76을 5등분, 물결 깊이 7 (y 80 → 87) |
| 눈 | 세로 타원 2개, 검정 | 중심 (38,48) (62,48), 반지름 6.6 × 9.4 |
| 눈동자 | 흰 원 1개씩 | 눈 중심에서 오른쪽 위 (+1.6, −2.4), 반지름 2.8 |
| 꼬리(마침표) | 원 | 중심 (101,82), 반지름 7 |

- 원본 파일: `brand/dot-2d.svg` (라이트), `brand/dot-2d-dark.svg` (다크), `brand/dot-2d-notail.svg` (꼬리 없음)
- 앱 코드: `index.html` 의 `DOT(mood, { size, tail, cls, label })`

## 2. 색

| 역할 | 라이트 | 다크 | 비고 |
|---|---|---|---|
| 몸·꼬리 | `#2b50ff` | `#5c7cff` | 앱의 `--accent` 와 같음 (테마 따라 자동) |
| 눈 | `#0a0a0a` | `#0a0a0a` | 테마와 상관없이 검정 |
| 눈동자 | `#ffffff` | `#ffffff` | |

- 몸 색은 `--accent` 만 쓴다. 다른 색으로 바꾸지 않는다(빨강 닷, 초록 닷 X).
- 그라데이션·그림자·광택은 2D에선 쓰지 않는다(그건 3D 버전의 역할).

## 3. 표정 (눈으로만)

입·볼터치 없이 눈 모양만 바꾼다.

| mood | 눈 | 쓰는 곳 |
|---|---|---|
| `base` | 기본 타원 + 눈동자 | 로고 점, 기본 안내 |
| `happy` | ^ ^ (위로 볼록한 선) | 보내기 완료, 대기 피드 비었음(All clear), 릴스 다 봄 |
| `wow` | 큰 타원 + 눈동자 | 알림 켜기 창, 친구 피드 첫 사진 부탁 |
| `look` | 눈동자가 왼쪽 | 빈 피드, 친구 없음, 없는 페이지 |
| `down` | 눈동자가 아래 | 연결 오류 |
| `sleepy` | — — (일자) | 릴스 새 사진 없음, 알림 없음 |
| `wink` | 왼쪽 기본 + 오른쪽 감음 | (예비) 초대·공유 |

## 4. 움직임

| cls | 동작 | 쓰는 곳 |
|---|---|---|
| `hop` | 통통 튐(눌렸다 늘어남) | 로고 점(시작·로그인 중), 보내기 완료, 릴스 다 봄 |
| `blink` | 3.6초마다 눈 깜빡 | 빈 피드, 친구 없음, 없는 페이지 |
| `float` | 위아래로 천천히 | 오류, 알림 켜기 창, 친구 피드 비었음 |
| `pop` | 한 번 튀어나옴 | 보내기 완료 등장 |

- 한 화면에 움직이는 닷은 하나만.
- 기기에서 "동작 줄이기"를 켜면 모든 움직임을 멈춘다.

## 5. 크기 규칙

| 크기 | 규칙 |
|---|---|
| 72px 이상 | 기본. 빈 화면·오류·완료 |
| 48–64px | 시트·패널 안 (알림 없음, 친구 고르기, 알림 켜기) |
| 24–40px | 꼬리 포함 가능 |
| 24px 미만 | **꼬리 없이** (로고 점 자리 등). 16px까지 |

- 비율을 늘리거나 찌그러뜨리지 않는다(애니메이션 제외).
- 주변에 몸 폭의 1/4 이상 여백.

## 6. 지금 앱에서 쓰는 곳 (2D)

| 화면 | 표정 · 움직임 | 크기 |
|---|---|---|
| 시작 화면 / 로그인 중 / 릴스 불러오는 중 | 로고 `candid` 뒤 마침표 자리, `base` · `hop` · 꼬리 없음 | 글자 크기의 0.62배 |
| 연결 오류 | `down` · `float` | 76 |
| 없는 피드·아이디 | `look` · `blink` | 76 |
| 내 피드 비었음 (Nothing here, yet) | `look` · `blink` | 72 |
| 친구 피드 비었음 (Be the first) | `wow` · `float` | 72 |
| 대기 피드 비었음 (All clear) | `happy` | 52 |
| 친구 탭 비었음 (No friends, yet) | `look` · `blink` | 72 |
| 릴스 새 사진 없음 (Quiet for now) | `sleepy` · `float` | 80 |
| 릴스 다 봄 (All caught up) | `happy` · `hop` | 80 |
| 보내기 완료 (Sent) | `happy` · `pop`+`hop` | 88 |
| 알림 켜기 창 | `wow` · `float` | 64 |
| 알림 없음 · 친구 고르기(친구 없음) | `sleepy` / `look` | 52 |

**앱 아이콘**: 3D(클레이) 닷 정면 + 위에서 비추는 빛(스포트라이트) + 바닥 그림자, 검정 바탕. 원본 `brand/icon.svg`, 크기별 `brand/icon-{1024,512,192,180,128,32}.png`, `apple-touch-icon.png`, `favicon.ico`.

쓰지 않는 곳: 로그인 첫 화면 로고, 상단 바 로고 — 브랜드 글자는 그대로 두고, 캐릭터는 "상태를 알려 주는 순간"에만 나온다.

## 7. 3D 닷 (클레이) — 정의만, 아직 미사용

- 모양·눈·꼬리는 2D와 완전히 같다. 질감만 다르다.
- **재질**: 무광 점토. 빛은 왼쪽 위 45°. 몸은 `#7d97ff → #3d5cff → #1d33b8` 방사형 그라데이션, 왼쪽 위 흐린 하이라이트, 아래쪽 어두운 그늘, 바닥에 흐린 그림자.
- **눈**: 위 `#2a2a33` → 아래 `#050508` 세로 그라데이션 + 흰 눈동자(평면 그대로).
- 시안 파일: `brand/dot-3d-clay.svg` (브라우저 그림으로 흉내 낸 것)
- **제작**: 실제 사용 전에는 Blender/Spline 등 3D 툴로 다시 만들어 PNG(투명 배경, 1024px 이상)로 뽑는다. 위 수치를 기준으로 맞춘다.
- **쓰는 곳**: 앱 아이콘(스포트라이트 버전, 위 6절)
- **쓸 곳(예정)**: 앱 스토어 스크린샷·홍보 이미지, 카톡 공유 미리보기(og 이미지), 초대 카드, 랜딩 페이지 메인, 굿즈·스티커 팩.
- 앱 화면 안에서는 2D만 쓴다(작은 크기·빠른 로딩·흑백 UI와의 조화).

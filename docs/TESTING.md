# TESTING — candid. 테스트 가이드

빌드 전 테스트는 **필수**다. 규칙 요약은 `AGENTS.md` 0번을 본다.

## 실행
```bash
node tests/run-tests.js   # 저장소 루트
cd ios-app && npm test    # 동일
```
성공: `ALL TESTS PASSED`, 종료 코드 0. 실패: `FAILED: n check(s)`, 종료 코드 1.
`ios-app/build-www.js`는 복사 전에 이 테스트를 `require`하므로, 실패하면 `ios-app/www`가 만들어지지 않는다.

## 자동 테스트 범위 (외부 의존성 없음)
`tests/run-tests.js`가 `index.html`을 읽어 다음을 검증한다.

1. **문법**: 인라인 `<script>` 4개를 `new Function`으로 파싱
2. **공통 모듈 단위 테스트**
   - `normSearch` — 공백/대소문자/`@` 제거, null 안전
   - `searchMatch` — 빈 검색어, `@핸들`, 이름/핸들, 이메일 옵션, 무결과
   - `recentPosts` — owner/group 단일·배열, `flagged`, `since`, `cols`, limit
   - `memberSub` — 방장·신청시각·@핸들·빈 값
   - `memberWho` — 피드 링크·아바타·이름
3. **작성 진입 공통화**: 선택 시 `closeSheet()` → `composeTarget()`, 래퍼 함수 위임
4. **은하 이름**: `Blue/Pink/Purple Orbit`, 한글 이름 잔존 없음
5. **i18n**: `tools/i18n-check.js` 누락 0
6. **동선/동작 배선** (화면 이동이 실제로 이어지는지)
   - ⊕ → 친구 피드 채워주기 / 그룹에 올리기 → 대상 선택 → 작성 화면
   - 그룹은 사진첩 바로, 친구는 일반 작성 화면
   - 그룹 화면의 “사진 올리기”
   - 궤도 탭: 트렌딩 → 소스 열기, 사진 없음 → 피드/그룹 이동, 있음 → 스택 열기
   - 트렌딩: 최근 사진 조회, 없음/오류 시 소스 페이지 폴백
   - 검색 결과 → 피드/그룹 링크
   - 그룹 관리: 승인/거절/더보기
   - 빈 목록에서 친구 찾기/그룹 만들기로 이어짐
7. **사진첩**: 스마트 모음 subtype 전환·선택 초기화·이전 응답 무시, 시트 닫힘/터치·세로 스크롤, 남은 오버레이 정리, 시트를 올린 직후 탭 가능
8. **투표·질문**: 파스텔 테마/블루닷 대비(제목 text-shadow), 투표 선택 취소·재투표·%와 인원, 인라인 다중 답변(개인=주인/그룹=멤버)
9. **작성 화면**: 가로 잠금, 한 손가락 세로 스크롤·두 손가락 사진 조정, 원본 해상도 크롭 후 업로드 압축(미리보기 원본)
   - 앨범 전환/시트 정리/작성 화면 제스처의 회귀는 `[13] recent fixes`에서 함께 검사

## 커버하지 않는 것
- 실제 DOM 클릭/E2E, Supabase 실호출, 레이아웃·시각 효과
- 이 부분은 시뮬레이터/브라우저에서 수동 확인한다.
- 자동 E2E가 필요하면 Playwright 도입을 제안한다(현재 미설치). 도입 시:
  - 데모 모드(`node ios-app/build-www.js --demo`의 `config.js`)로 서버 없이 플로우를 돌리거나,
  - 테스트 전용 Supabase 프로젝트/시드 계정을 사용한다.

## 수동 시뮬레이터 체크리스트
1. ⊕ → 친구 피드 채워주기 → 친구 선택 시 **선택 시트가 닫히고** 사진 선택이 올라온다
2. ⊕ → 그룹에 올리기 → 그룹 선택 시 **그룹 시트가 먼저 닫힌다**(이전 버그)
3. 친구 선택 검색(이름/@아이디), 그룹 선택 목록/빈 상태
4. 전역 검색: 사람 + 내 그룹 + 공개 그룹, `@` 검색
5. 그룹 초대 → 친구 골라서 초대
6. 그룹 관리: 승인/거절/멤버 더보기
7. 홈 피드 로드(2주 내 글, 부족 시 40개 폴백)
8. Pink Orbit 노드 탭 → 최근 사진 열림, 없으면 피드/그룹으로 이동
9. 그룹 멤버 목록/관리 라벨(방장·신청시각·@아이디)
10. 사진첩에서 다른 스마트 모음(즐겨찾기/비디오 등)으로 전환 → 사진 선택/해제, 추가 버튼
11. 사진첩 시트를 위로 올렸다가 닫은 뒤 → 작성 화면 취소/사진 선택/앨범 버튼이 모두 터치되는지
12. 사진첩 세로 스크롤, 사진 칸 탭 선택, 드래그 직후 바로 탭
13. 작성 화면 가로 흔들림 없음 + 한 손가락 세로 스크롤, 두 손가락 사진 이동/확대, 확대 크롭 화질
14. 투표 다시 눌러 취소/재투표, 결과 %와 인원 수
15. 질문 답변이 프로필과 함께 질문 아래 인라인으로 여러 개 표시(개인=주인/그룹=멤버)
16. 작성/사진 편집 화면에서 사진 **밖**을 위로 드래그하면 화면이 아래로 스크롤되고, 맨 위에서 당겨도 새로고침되지는 않는다(빌드 26 회귀)
17. Candids 전체화면에서 사진 삭제/피드에서 내리기 → 화면이 즉시 닫히고 피드·그룹 목록에서도 바로 사라진다
18. 보내기/올리기 → **“이 피드를 올릴까요?” 확인 팝업**이 뜬다. 취소하면 작성 내용이 유지되고, 확인해야만 업로드된다(그룹은 그룹명 표시)
19. 보관함 → **내가 보낸 피드**: 승인 대기 글만 보이고 `보내기 취소`로 취소된다. 이미 상대방이 승인한 글은 보관함에 보이지 않는다
20. 한 그룹에 30분 안에 여러 장이 올라와도 Candids에서 **전부 표시**되고 `+N장 더 올라왔어요`가 뜨지 않는다
21. 투표·질문 작성: 두 탭 모두 `무엇을 물어볼까요?` 플레이스홀더가 보이고, 별도 박스·테두리·포커스 테두리는 없다
22. 작성 화면 상단에 **보내는 사람**이 보이고(그룹 포함), 사진 편집 중 페이지가 좌우로 흔들리거나 확대되지 않는다

## 유지보수 메모
- 동선 검증은 `index.html`의 실제 문자열/구조를 정규식으로 확인한다. 리팩터링으로 문자열이 바뀌면 테스트가 실패할 수 있으니, **동작이 유지되는 경우에만** 검증을 갱신한다.
- 공통 모듈 단위 테스트는 `const normSearch =`부터 `const memberWho =` 줄 끝까지를 잘라 평가한다. 위치가 바뀌면 추출 구간을 갱신한다.

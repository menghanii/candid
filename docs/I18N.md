# 다국어 (i18n)

지원 언어: **한국어(ko, 원문)** · **English(en)** · **日本語(ja)**

## 동작

1. `index.html` 맨 위 작은 스크립트가 언어를 정한다.
   - 메뉴에서 고른 언어(`localStorage.candid_lang`)가 있으면 그것
   - 없으면 기기 언어(`navigator.languages`)에서 지원하는 첫 언어
   - 둘 다 없으면 영어
2. 한국어가 아니면 `i18n/<코드>.js` 사전을 **그 언어 것만** 불러온다.
3. 화면 문구는 `t('한국어 원문', { 변수 })` 로 쓴다. 사전에 번역이 없으면 한국어 원문이 그대로 나와서 앱이 깨지지 않는다.
4. ☰ 메뉴 → 🌐 언어 에서 바꾸면 기억하고 새로고침한다.

## 문구 쓰는 법

```js
t('보내기')                                         // 단순 문구
t('{name}님이 승인하면 피드에 올라가요', { name })      // 자리 표시
t(mode === 'poll' ? '투표' : '질문')                  // 조건: 두 문구 모두 사전에 넣기
```

- 키는 **한국어 원문 그대로**다. 원문을 고치면 각 사전의 키도 같이 고친다.
- 변수 값은 그대로 끼워 넣는다. 사용자 입력은 `esc()` 한 값을 넘긴다.
- DB에 한국어로 저장되는 값(미션 이름, `익명의 친구`, `투표`/`질문`)은 저장은 그대로 두고 **보여줄 때** `t(값)` 으로 바꾼다.

## 새 언어 추가 (예: 중국어 간체 zh)

1. `index.html` 맨 위 스크립트의 목록에 한 줄: `{ ko: '한국어', en: 'English', ja: '日本語', zh: '简体中文' }`
2. `i18n/en.js` 를 복사해 `i18n/zh.js` 로 만들고, 맨 아래 `.en =` 을 `.zh =` 로 바꾼 뒤 값만 번역
3. `node tools/i18n-check.js` 로 빠진 문구 확인
4. (푸시 알림) `supabase/functions/notify-owner` 의 문구 표에도 추가 — 3단계에서 적용 예정

## 점검 도구

```bash
node tools/i18n-check.js
```

`t('…')` 로 쓴 문구 중 각 사전에 없는 것을 보여준다. `t(변수)` 로 넘기는 문구는 코드에서 안 보이므로 "(참고) 직접 안 보이는 번역"으로 따로 센다.

## 진행 상황

| 단계 | 범위 | 상태 |
|---|---|---|
| 1 | 링크 받은 친구 흐름: 첫 화면·로그인, 친구 피드, 보내기·완료, 설치 안내, 오류, 없는 페이지, 시간 표시, 언어 메뉴 | ✅ |
| 2 | 가입 후 화면: 내 피드·대기 피드·친구·릴스·알림(목록·켜기)·메뉴·꾸미기·댓글·검색·프로필 설정·초대·부탁하기·투표/질문·스토리 이미지 | ✅ |
| 3 | 푸시 알림을 받는 사람 언어로(프로필에 언어 저장) · 가챠(꺼져 있음) | 예정 |

`tools/i18n_phase1.py`, `tools/i18n_phase2.py` 는 단계별 문구 표(한국어·영어·일본어)와 코드 치환·사전 생성 기록.

번역하지 않는 것: 사람이 쓴 글(이름·메시지·댓글), 데모 데이터, 꺼 둔 가챠 화면.
